# 🚀 Features

- 📖 **Interactive Question Dashboard**
  - Responsive sidebar navigation
  - Organized by modules
  - Quick access to topics and questions

- 📝 **Step-by-Step Solutions**
  - Detailed explanations
  - Covers Part A questions
  - Covers Part B questions
  - Easy-to-follow mathematical reasoning

- ➗ **Advanced Mathematical Rendering**
  - Beautiful LaTeX equations
  - Clean theorem formatting
  - Mathematical proofs rendered using KaTeX

- 📊 **Interactive Diagrams**
  - Hasse Diagrams
  - Directed Graphs
  - Relation Graphs
  - Custom React-based visual components

- 📱 **Responsive Design**
  - Desktop
  - Tablet
  - Mobile

- 🌙 **Modern User Interface**
  - Clean layout
  - Fast navigation
  - Smooth user experience

# 📦 Prerequisites

Before running the project, install:

- Node.js **v18 or later**
- npm (comes with Node.js)

Verify installation:

```bash
node -v
npm -v
```

---

# 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ATS-001/Discrete-Maths-ModelPaper24.git
```

### 2. Navigate into the project

```bash
cd KTU-Discrete-Math-Solutions
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

or

```bash
pnpm install
```

---

# ▶️ Running the Development Server

```bash
npm run dev
```

or

```bash
yarn dev
```

or

```bash
pnpm dev
```

Open your browser and visit:

```
http://localhost:3000
```

# 🎯 Purpose

This project is built to help KTU students prepare for the **Discrete Mathematics (2024 Scheme)** course by providing:

- Module-wise solutions
- Step-by-step explanations
- Mathematical proofs
- Graph theory diagrams
- Set theory concepts
- Logic and propositional reasoning
- Relations and functions
- Lattice and Boolean algebra topics

through an interactive and easy-to-use web application.
